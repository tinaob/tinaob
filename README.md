##  Security Projects

###  [Phishing Email Analyzer](https://github.com/tinaob/phishing-email-analyzer)
A Python tool that detects phishing indicators in `.eml` email files using 
header analysis and VirusTotal API scanning. Built to simulate the kind of 
triage work done in a SOC Tier 1 environment.

###  [Log Analyzer / SIEM Simulation](https://github.com/tinaob/log-analyzer)
A Python-based SIEM simulation tool that analyses log files to detect brute 
force attacks, unusual login hours, and targeted user accounts — replicating 
core detection logic used in real security operations.

###  [Vulnerability Scanner](https://github.com/tinaob/vulnerability-scanner)
A Python vulnerability scanner using Nmap to detect open ports, identify 
running services, assess risk levels, and generate timestamped CSV security 
reports. Designed to mirror entry-level penetration testing workflows.

###  [Cloud Security Misconfiguration Scanner](https://github.com/tinaob/cloud-security-scanner)
A Python tool that connects to a real AWS account using boto3 and audits it for critical security misconfigurations — including IAM users without MFA, root account usage, exposed S3 buckets, and old access keys. Tested against a live AWS environment with real findings documented.
